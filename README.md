# BiliMind Desktop

Open-source, local-first AI study studio. Turn any topic or source into a course, notes,
flashcards, quizzes and audio overviews, all saved as Markdown files you own. Bring your own AI
key (OpenRouter, OpenAI, Anthropic, Gemini) or run fully offline with Ollama.

**Status:** planning. Work starts from [`plan/opensource.md`](plan/opensource.md).
