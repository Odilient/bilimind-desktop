# Spike workspace

Select this folder as the WorkBuddy workspace for the spike (input box, bottom right, "Select Folder").

- `.codebuddy/skills/bilimind-spike-ws/` is a project-level skill used to answer S2 (does a workspace
  skill load in Work mode?).
- The spike writes its outputs to `spike-out/` here: `info.json`, `parallel.jsonl`,
  `parallel-report.json`, `spike.html`, `sample.mp3`, `sources/x.pdf`, `SPIKE-RESULT.md`.

See `hackathon/SPIKE.md` for the exact messages to paste and the results form.
