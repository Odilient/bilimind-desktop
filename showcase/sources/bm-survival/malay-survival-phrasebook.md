# Bahasa Melayu Survival Phrasebook: your first month in Malaysia

A practice companion for international students (mamak, Grab, campus). It is not the official Bahasa Melayu
Komunikasi (BMK) syllabus.

Adapted from the Wikivoyage article "Malay phrasebook" (https://en.wikivoyage.org/wiki/Malay_phrasebook),
licensed CC BY-SA 4.0. Rows marked † were added for this demo (mamak ordering, Grab, campus, everyday
Malaysian usage). This file is shared under CC BY-SA 4.0. See LICENSE.md.

## 1. How Malay sounds

Malay is written in the Latin alphabet (Rumi) and is mostly spelled as it sounds.

| Letter | Sounds like | Example |
|---|---|---|
| a | "a" in *father*; at the end of a word, often a soft "uh" in everyday Peninsular speech | *saya* (I) sounds like "sa-yuh" |
| e | usually a short "uh" (like the "a" in *about*); sometimes "e" in *bed* | *besar* (big) "buh-sar"; *meja* (table) "meh-ja" |
| i | "ee" in *see* | *ikan* (fish) |
| o | "o" in *low*, without the "w" | *kopi* (coffee) |
| u | "oo" in *food* | *susu* (milk) |
| c | always "ch" in *China* | *cakap* (speak) "chah-kahp" |
| g | always hard, as in *go* | *gula* (sugar) |
| j | "j" in *jug* | *jalan* (road) |
| ng | "ng" in *singer* (no hard g) | *dengan* (with) |
| ngg | "ng" in *finger* | *tangga* (stairs) |
| ny | "ny" in *canyon* | *nyanyi* (sing) |
| sy | "sh" in *shop* | *syarikat* (company) |
| kh | "ch" in Scottish *loch*, often softened to "k" | *khabar* (news) |
| r | a tapped r; at the end of a word often dropped in casual speech | *besar* can sound like "besa" |
| final k | a short stop in the throat, not a full "k" | *tidak* (no) sounds like "tida'" |

Stress is light and fairly even; many speakers lean slightly on the second-last syllable.

## 3. Being polite: what to call people

| Word | Use it for | Notes |
|---|---|---|
| saya | I, me | polite, safe everywhere |
| aku | I, me | only with close friends |
| awak / anda | you | *anda* is neutral and formal (signs, ads); *awak* is friendly |
| kamu | you | for children or close friends; can sound rude to older people |
| Encik | Mr, sir | any adult man |
| Puan | Mrs, madam | a married or older woman |
| Cik | Miss | a young woman |
| Abang / Bang | "older brother" | friendly for a man a bit older than you: the mamak waiter, a Grab driver |
| Kakak / Kak | "older sister" | friendly for a woman a bit older than you |
| Adik / Dik | "younger sibling" | for someone younger than you |
| Pak cik / Mak cik † | "uncle" / "auntie" | older man / older woman, for example a stall owner |

Tip: Malaysians often avoid the word "you". Use the title instead: *Bang, nak order.* (Brother, I'd like to order.)

## 4. Numbers and money

| Number | Malay | Number | Malay |
|---|---|---|---|
| 0 | sifar (kosong †, e.g. phone numbers) | 11 | sebelas |
| 1 | satu | 12 | dua belas |
| 2 | dua | 13 | tiga belas |
| 3 | tiga | 19 | sembilan belas |
| 4 | empat | 20 | dua puluh |
| 5 | lima | 21 | dua puluh satu † |
| 6 | enam | 30 | tiga puluh † |
| 7 | tujuh | 50 | lima puluh † |
| 8 | lapan | 100 | seratus |
| 9 | sembilan | 1,000 | seribu |
| 10 | sepuluh | 1,000,000 | sejuta |

Pattern: *se-* means "one": *sepuluh* (10), *sebelas* (11), *seratus* (100), *seribu* (1,000).
Teens add *belas*: *tiga belas* = 13. Tens add *puluh*: *tiga puluh* = 30.

Money: RM = ringgit; 1 ringgit = 100 sen. RM 4.50 = *empat ringgit lima puluh sen*.

| Malay | English |
|---|---|
| Berapa harga ini? | How much is this? |
| Berapa semua? † | How much altogether? |
| mahal / terlalu mahal | expensive / too expensive |
| murah | cheap |
| Boleh kurangkan harganya? | Can you lower the price? |
| Boleh saya guna kad kredit? | Can I use a credit card? |
| Bayar tunai. † | Pay cash. |

## 5. At the mamak †

A *mamak* is a Malaysian Indian-Muslim restaurant, often open late or 24 hours. You order at the table.

Drinks:

| Order | What you get |
|---|---|
| teh | hot tea with condensed milk (the default) |
| teh tarik | "pulled" frothy milk tea |
| teh ais | iced milk tea |
| teh O | tea without milk, with sugar |
| teh O ais | iced tea without milk, with sugar |
| teh O ais limau | iced lime tea |
| kopi / kopi O | coffee with condensed milk / black coffee with sugar |
| Milo ais | iced Milo |
| air suam | warm water |
| air kosong | plain water |

Changing an order:

| Malay | English |
|---|---|
| kurang manis | less sweet |
| kosong | no sugar (*teh O kosong* = black tea, no sugar); for roti it means plain |
| tak nak gula | no sugar, please |
| ais / panas | iced / hot |
| tak nak pedas / kurang pedas | not spicy / less spicy |
| makan sini | eat here |
| bungkus / tapau | takeaway (*tapau* comes from Cantonese) |
| satu lagi | one more |

Food: *roti canai* (flaky flatbread with curry), *roti kosong* (plain roti), *roti telur* (roti with egg),
*nasi lemak* (coconut rice with sambal, anchovies, peanuts and egg), *mee goreng mamak* (mamak fried noodles;
Wikivoyage spells noodles *mi*, menus often write *mee*), *kuah campur* (mixed curry gravy).

Dialogue:

> **Waiter:** Nak minum apa? *(What would you like to drink?)*
> **You:** Teh tarik kurang manis, satu. *(One teh tarik, less sweet.)*
> **Waiter:** Makan? *(Anything to eat?)*
> **You:** Roti canai satu, kuah campur. *(One roti canai, mixed curry.)*
> *(Later)* **You:** Bang, kira. *(The bill, please.)*
> **Waiter:** Empat ringgit lima puluh sen. *(RM 4.50.)*
> **You:** Terima kasih, bang!

## 6. Grab and getting around †

| Malay | English |
|---|---|
| Saya nak pergi ke Taylor's, Lakeside Campus. | I want to go to Taylor's Lakeside Campus. |
| Abang dah sampai? | Have you arrived? (to the driver) |
| Saya dah sampai. | I've arrived. |
| Saya tunggu di pintu utama. | I'm waiting at the main entrance. |
| Saya pakai baju biru. | I'm wearing a blue shirt. |
| Saya lambat sikit, lima minit. | I'm a bit late, five minutes. |
| Belok kiri. / Belok kanan. | Turn left. / Turn right. (Wikivoyage: *Pusing kiri / Pusing kanan*) |
| Jalan terus. | Go straight on. |
| Pusing balik. | Make a U-turn. |
| Tolong berhenti di sini. | Please stop here. |
| dekat / jauh | near / far |
| Jalan sesak. / Jem. | Traffic is heavy. / Traffic jam. |
| Berapa lama? | How long will it take? |
| Berapa harga tiket ke KL Sentral? | How much is a ticket to KL Sentral? |
| Tren ini pergi ke mana? | Where does this train go? |

## 8. Time and days

| Malay | English |
|---|---|
| sekarang | now |
| hari ini | today |
| semalam | yesterday (also "last night") |
| esok | tomorrow (Wikivoyage lists *besok*, which is also understood) |
| pagi / tengah hari / petang / malam | morning / midday / afternoon to dusk / night |
| Pukul berapa sekarang? | What time is it now? |
| pukul satu / pukul dua setengah | one o'clock / half past two |

Days: Isnin (Monday), Selasa (Tuesday), Rabu (Wednesday), Khamis (Thursday), Jumaat (Friday), Sabtu (Saturday),
Ahad (Sunday).

## 9. Problems

| Malay | English |
|---|---|
| Tolong! | Help! |
| Saya tersesat. | I'm lost. |

| Saya perlu doktor. | I need a doctor. |
| Panggil polis! † | Call the police! |
| Saya alah kepada susu. † | I'm allergic to milk. (*Saya alergi susu* is also common.) |

Emergency number in Malaysia: **999** (112 also works from a mobile phone).
